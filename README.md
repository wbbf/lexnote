# 렉스노트 소개 페이지

법무사 사무소 사건관리 프로그램 렉스노트의 한 쪽 소개 페이지입니다. 화면·영상 예시는 모두 가상 자료입니다.

- 주소: https://wbbf.github.io/lexnote/
- 시연 영상(demo1~3.mp4)은 src/demo.html?s=1~3 장면을 Playwright로 녹화해 mp4로 바꾼 것입니다.

- 2026-11-19 완전 개편: 어두운 첫 화면 + 실제 프로그램 화면(img/*.webp, 렉스노트 1.0.586을 가상 자료로 찍은 것), 업무 흐름 7단계, 주요 기능 셋, 기능 12개, 비교표, 시연 영상, 공공데이터·보안. 휴대폰 화면 대응. 시안: Figma '렉스노트 소개 홈페이지 개편 시안'.
