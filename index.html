WHY LEXNOTE

왜 렉스노트인가

기능의 개수보다, 사무소에서 매일 쓰는 데 무엇이 다른지를 정리했습니다.

01현장 개발

사무장이 매일 쓰면서
고쳐 온 프로그램

실제 법무사 사무소의 사무장이 등기·송무·집행 사건을 처리하며 직접 쓰고, 막히는 곳을 그때그때 고쳐 왔습니다. 화면 순서가 실제 일하는 순서와 같습니다.

사무소 실사용 중 접수된 요청을 반영해 계속 판을 올리고 있습니다.
02서식 그대로

등기 서류는
원본 서식에 값만 채웁니다

표를 새로 그리지 않고 인터넷등기소 신청서 서식 원본에 내용을 채워 hwpx로 만듭니다. 손으로 다시 맞출 일이 줄어듭니다.

인터넷등기소에서 제공하는 신청서 양식을 원본으로 사용합니다.
03법령 기준

세금·채권·송달료를
법령과 예규대로 계산

취득세·등록면허세·국민주택채권·송달료를 현행 법령과 대법원 예규 기준으로 계산합니다. 근거 법령이 바뀌면 개정 소식을 알려 줍니다.

법제처 법령 정보로 근거 조문의 개정 여부를 확인합니다.
04한 번 입력

한 번 적은 정보가
끝까지 이어집니다

의뢰인·거래처·부동산 정보를 한 번 입력하면 신청서, 비용 안내서, 영수증, 사건부, 전자세금계산서에 그대로 이어집니다.

주소는 도로명주소, 부동산 표시는 건축물대장에서 불러와 오기를 줄입니다.
05자동 정리

받은 서류는
알아서 사건을 찾아갑니다

접수증과 기일통지서를 읽어 맞는 사건이 하나면 바로 기일을 등록하고, 없거나 여럿이면 사람에게 확인을 받습니다. 알림은 7일 전·전날·당일.

자동 등록은 일치하는 사건이 정확히 1건일 때만 합니다.
06보안

사무소 자료는
사무소 밖으로 나가지 않습니다

사건 자료는 사무소 PC와 내부 저장소(NAS)에만 두고, 주민등록번호는 암호화해 보관합니다. 저장소가 꺼져도 읽기 전용으로 열어 볼 수 있습니다.

사건목록 화면과 사건부 인쇄물에는 주민등록번호 앞 6자리만 표시합니다.

ABOUT

렉스노트는 어떤 프로그램인가요

실제 법무사 사무소의 사무장이 매일 업무에 직접 사용하면서 불편한 점을 하나씩 고쳐 다듬고 있는 프로그램입니다.

대상

누구를 위한 프로그램

등기·송무·집행·회생파산 사건을 함께 처리하는 법무사 사무소의 법무사와 직원이 같이 씁니다. 사무소 안의 여러 PC가 하나의 자료를 나눠 봅니다.

문제

무엇을 줄여 주나

사건마다 엑셀 장부, 한글 서식, 계산기, 달력을 오가며 같은 이름과 주소를 여러 번 적던 일을 줄입니다. 한 번 입력한 정보가 신청서·영수증·사건부에 이어집니다.

방식

어떻게 동작하나

Windows PC에 설치해 쓰고, 자료는 사무소 내부 저장소에 둡니다. 주소·건축물대장·공시가격 같은 공개 정보만 공공데이터로 조회합니다.

현장에서 쓰면서 만듭니다 렉스노트는 책상 위에서 설계만 한 프로그램이 아닙니다. 실제 법무사 사무소의 사무장이 등기·송무·집행 사건을 처리하며 직접 사용하고, 쓰다가 막히거나 번거로운 부분을 그때그때 고쳐 왔습니다. 화면 배치, 계산 방식, 서식 하나하나가 실제 업무 순서에 맞춰져 있습니다.

사무소 업무 전 과정을 한 프로그램으로

흩어진 엑셀과 한글 파일 대신, 사건 하나에 필요한 정보와 서류를 모아 둡니다.

목록

사건목록·사건부

수임부터 접수·교부·입금까지 진행 단계를 한 표로 봅니다. 사건부 번호는 수임일 순으로 자동 정리됩니다.

등기

등기자동화

부동산·상업등기 신청서를 인터넷등기소 서식 그대로 채워 hwpx로 만듭니다. 여러 건도 한 번에.

비용

비용산출

취득세·등록면허세·국민주택채권·수수료·보수를 법령 기준으로 계산하고 견적서·영수증을 인쇄합니다.

임기

임원 임기관리

거래처 법인 임원의 임기 만료를 미리 알려 주고, 만료 안내문을 한꺼번에 만듭니다.

회생

회생·파산

채권자 목록과 재산 목록을 입력하면 청산가치·변제 계획 계산과 신청서 작성을 돕습니다.

세금

전자세금계산서

사건 비용 정리 화면에서 바로 전자세금계산서를 발급·취소하고 거래처 정보를 함께 저장합니다.

기일

기일·기한 알림

법원 기일 통지서를 읽어 사건에 기일을 등록하고, 7일 전·전날·당일에 알려 줍니다.

계산

이자·원리금 계산

여러 원금과 이율 변경, 일부 변제를 시간 순서대로 반영해 원리금 계산표를 만듭니다.

거래

거래처 관리

자주 오는 법인·개인 의뢰인을 저장해 두고, 상호의 약칭은 정식 명칭으로 바로잡아 입력합니다.

서명

교부·서명 패드

완료 서류를 방문 수령할 때 태블릿에 서명을 받아 기록하고, 등기우편 교부도 함께 관리합니다.

읽기

받은 서류 자동 정리

접수증·기일통지서·소환장을 읽어 해당 사건을 찾아 기록하고, 맞는 사건이 없으면 확인을 요청합니다.

마감

사건부·월 마감

달마다 사건부를 마감해 번호를 고정하고, 지방법무사회 제출용 사건부를 인쇄합니다.

공시지가·공시가격 확인

토지·주택 공시가격을 조회해 시가표준액을 확인하고 세금·채권 계산의 기준으로 씁니다.

데이터제공 기관렉스노트에서 쓰는 곳조회 시점
도로명주소행정안전부의뢰인·거래처 주소, 부동산 소재지, 법인 본점 주소 입력주소 검색 단추를 누를 때
건축물대장국토교통부 (공공데이터포털)부동산 표시(구조·면적·용도)와 신축·증축 여부 확인, 신청서·비용산출 반영부동산 표시를 불러올 때
개별공시지가·주택가격국토교통부 (브이월드)시가표준액 확인, 취득세·등록면허세·국민주택채권 계산의 기준 금액비용산출에서 금액을 조회할 때
법령 정보법제처세율·수수료 근거 법령의 개정 여부 확인과 개정 알림법령 개정 여부를 확인할 때
조회 흐름
1사용자가 요청주소나 지번을 입력하고 조회 단추를 누름
2공공데이터 조회필요한 항목만 해당 기관 API에 요청
3사용자 확인결과를 화면에 보여 주고 맞는지 확인
4사건에 반영확인한 값만 신청서·계산에 사용
조회 결과는 사용자의 업무 처리에만 쓰며, 원 데이터를 다른 사람에게 재배포하지 않습니다. 개인정보(주민등록번호 등)는 공공데이터 조회에 보내지 않습니다.
PRINCIPLES

사무소 자료는 사무소 안에

사무소 저장소 보관

사건 자료는 사무소 PC와 내부 저장소(NAS)에만 저장합니다.

주민등록번호 암호화

주민등록번호는 암호화해 보관하고, 목록 화면에서는 앞자리만 보여 줍니다.

현행 법령 기준

세율·수수료·송달료는 현행 법령과 대법원 예규 기준으로 계산하고, 개정 소식을 알려 줍니다.
